## 🦅 О проекте

**REDSKIN ASSASSIN (TOMAHAWK OSINT)** — это профессиональный веб-инструментарий оперативной кибер-разведки, валидации идентификаторов РФ и анализа открытых источников (OSINT) без фейковых генераторов и симуляций.

Каждый модуль выполняет **реальные вычисления, проверку математических контрольных сумм по алгоритмам ФНС/ПФР/ГИБДД/ISO**, прямые запросы к публичным реестрам, DoH DNS-резолвинг, извлечение метаданных EXIF и анализ блокчейн-сетей.

## ⚡ Реальные OSINT Модули

### 1. 🪪 Алгоритмическая Валидация Идентификаторов РФ
- **ИНН ЮЛ (10 знаков)**: Официальный полиномиальный расчет контрольной цифры по формуле ФНС РФ с весовыми коэффициентами `[2, 4, 10, 3, 5, 9, 4, 6, 8, 0] % 11 % 10`, определение региона ФНС и кода инспекции.
- **ИНН ФЛ/ИП (12 знаков)**: Двойной расчет 11-й и 12-й контрольных цифр по формулам налоговой службы, валидация статуса ИП.
- **СНИЛС РФ**: Полная проверка 11-значного номера по алгоритму Пенсионного Фонда РФ (суммирование с весами от 9 до 1, правило `mod 101`), обработка архивного диапазона.
- **ОГРН / ОГРНИП**: Проверка 13-значного ОГРН юридического лица (`mod 11`) и 15-значного ОГРНИП индивидуального предпринимателя (`mod 13`), определение года регистрации и кода субъекта РФ.
- **Паспорт Гражданина РФ**: Проверка серии и номера по классификатору регионов ОКАТО (все 89 субъектов РФ), оценка года выдачи и валидности.
- **БИК Банков РФ**: Проверка 9-значного банковского идентификатора расчетов ЦБ РФ и определение кредитной организации.

### 2. 🚗 Идентификация Автотранспорта (ГРЗ & VIN)
- **Госномер РФ (ГРЗ)**: Распознавание форматов (Тип 1, Такси, Спецсерии АМР/ЕКХ/СКР), привязка к полной базе всех 89 регионов РФ с отображением федерального округа.
- **Декодер VIN (ISO 3779)**: 17-значный анализ с проверкой 9-го контрольного знака (mod 11), определение производителя по WMI (BMW, Mercedes-Benz, Porsche, Lada, Toyota и др.), модельного года выпуска и сборочного завода.

### 3. 📡 Телеком-Маршрутизация & Мессенджеры
- **DEF-коды РФ**: Анализ емкостей мобильных операторов (МТС, Билайн, МегаФон, Т2, Yota, Т-Мобайл, СберМобайл) и региона привязки сим-карты.
- **Прямые ссылки на мессенджеры**: Быстрый переход в Telegram (`t.me/+7...`), WhatsApp Click-to-Chat API, Viber, NumBuster и спам-базы.

### 4. 🌐 Сетевая Разведка & DNS-over-HTTPS
- **Live IP Geolocation**: Определение реального провайдера (ISP), номера автономной системы (ASN), организации, города, страны и географических координат.
- **Cloudflare DNS-over-HTTPS (DoH)**: Запросы ресурсных записей A, AAAA, MX, TXT, NS, SPF и DMARC напрямую из браузера без сторонних прокси.
- **Email & MX Inspector**: Проверка синтаксиса RFC 5322, фильтрация временных одноразовых почтовых ящиков (Disposable), проверка наличия активных почтовых MX-серверов и прямые ссылки на HIBP / IntelX.
- **Криптографический Калькулятор**: Генерация хэшей MD5, SHA-1, SHA-256, SHA-512 через Web Crypto API.

### 5. 💰 Анализ Криптовалютных Адресов
- **Bitcoin (BTC)**: Распознавание Legacy (1...), Script Hash (3...), Native SegWit (bc1q...) и Taproot (bc1p...).
- **Ethereum / EVM**: Валидация адресов 0x и ERC-20 токенов (USDT), live-запрос баланса через публичные RPC узлы.
- **TRON (TRX / TRC-20)**, **Solana (SOL)**, **Monero (XMR)**: Проверка контрольных форматов и прямые переходы в обозреватели блокчейна.

### 6. 🔎 Кросс-Платформенный Поиск Юзернейма (Sherlock Engine)
- Мгновенная генерация и проверка профилей на 22+ платформах: Telegram, VKontakte, GitHub, Twitter/X, Instagram, TikTok, Reddit, YouTube, Habr, Pikabu, Steam, Chess.com и др.

### 7. 📸 Экспертиза Изображений & Метаданных (EXIF & Forensics)
- **Извлечение EXIF**: GPS-координаты с прямой ссылкой на Яндекс Карты и Google Maps, марка и модель камеры, объектив, дата и время съемки, параметры ISO/выдержки.
- **Детектор Редактирования**: Определение факта обработки в Adobe Photoshop, Lightroom, VSCO, GIMP.
- **Error Level Analysis (ELA)**: Визуальный анализ градиента ошибок сжатия JPEG на HTML5 Canvas для обнаружения фотомонтажа и склеек.
- **Обратный поиск фото**: Прямые поисковые запросы для Яндекс Картинок, Google Lens, TinEye, PimEyes.

### 8. 🗂️ Локальное Управление Делами & Экспорт в PDF
- Хранение всех расследований в локальной базе `LocalStorage` браузера без отправки на сервер.
- Экспорт и импорт дел в формате JSON.
- Генерация официального отчета в формате PDF высокого разрешения.

## 🚀 Быстрый Запуск

### 💻 Локальная разработка:
```bash
git clone https://github.com/karalik19-a11y/redskinassasin.git
cd redskinassasin
npm install
npm run dev
```
Сервер откроется по адресу: `http://localhost:5173`.

### 📦 Сборка:
```bash
npm run build
```
