## 🦅 О проекте

**REDSKIN ASSASSIN (Томагавк OSINT)** — это веб-приложение нового поколения, выполненное в виде **дорогого премиального приложения для iPhone уровня флагманских сервисов**.

В приложении можно ввести **Фамилию, Имя, Отчество**, **Дату рождения**, **Номер телефона**, **Паспорт РФ**, **Госномер автомобиля** или загрузить **фото лица** для мгновенного построения исчерпывающего оперативного досье.

Дизайн вдохновлен духовной символикой **коренных индейцев Северной Америки** (ловцы снов, тотемные животные, боевая раскраска, священные орлы и волки) в гармоничном синтезе с **киберпанком, шифрованием и терминальной хакерской культурой**.

## ⚡ Ключевые возможности

### 1. 🪪 Мульти-векторный поиск и деанонимизация
- **Вектор ФИО + ДР**: Фамилия Имя Отчество + Дата рождения + Регион поиска.
- **Вектор Телеком**: Мобильные номера, Telegram ID/Username, Email адреса.
- **Вектор Документы**: Паспорт гражданина РФ, Загранпаспорт, ИНН, СНИЛС, Водительские права.
- **Вектор Транспорт**: Госномер автомобиля (ГРЗ), VIN, СТС, штрафы ГИБДД.
- **Вектор Биометрия (Face ID / Warpaint HUD)**: Сканирование фото лица с нанесением кибер-индейской раскраски и распознаванием вектора признаков.
- **Процедурный генератор**: При вводе абсолютно любого имени или даты формируется реалистичное, структурированное 360-градусное досье с непротиворечивыми связями, адресами и банками!

### 2. 📱 Опыт топового приложения iPhone (iOS 18 Liquid Glass)
- **Dynamic Island**: Интерактивный остров в верхней части с пульсацией, статусом шифрования, прогрессом сканирования и уведомлениями об угрозах.
- **Apple Haptic Synthesizer**: Реалистичный генератор тактильных звуков щелчков, сканирования, тотемного резонанса и успеха через Web Audio API (без внешних аудиофайлов).
- **Интерактивный фрейм iPhone 16 Pro**: Переключение между реалистичным титановым корпусом iPhone 16 Pro и полноэкранным адаптивным режимом.
- **Плавающая нижняя панель (Liquid Glass TabBar)**: Плавная навигация между разделами с индикаторами активности.

### 3. 📑 Подробнейшие разделы досье
- **Удостоверение личности & Реестры**: Паспорт РФ, Загранпаспорт (визы США, ОАЭ, Шенген), ИНН, СНИЛС, адреса постоянной регистрации и фактического проживания.
- **Телекоммуникации & Соцсети**: Все номера телефонов, IMSI/IMEI, сотовые операторы, теги из утечек GetContact/NumBuster, Telegram-профиль со слитыми сообщениями и закрытыми группами.
- **Финансы & Криптовалюта**: Оценочный совокупный капитал, счета в банках (Сбер, Т-Банк, Альфа, Emirates NBD), криптовалютные кошельки (BTC, USDT TRC-20, Monero XMR), доли в компаниях и ООО.
- **Имущество & Транспорт**: Автопарк (Porsche, Mercedes-Maybach, Bentley, BMW M5), госномера, VIN, штрафы ГИБДД, элитная недвижимость (Москва, СПб, Дубай).
- **Ловец Снов — Граф Связей**: Семейный круг (родители, супруги, дети, бизнес-партнеры, охрана). Клик по любому родственнику мгновенно открывает его персональное досье!
- **Утечки баз данных (Tomahawk Leaks)**: Точные данные из утечек Яндекс.Еда, СДЭК, Delivery Club, Альфа-Банк, Гемотест с адресами, суммами и расшифровкой паролей.
- **Орлиный Глаз — Геолокация**: Интерактивная карта перемещений, перелеты бизнес-классом, фиксации парковок ЦОДД и погранконтроля ФСБ.
- **Психологический портрет & Компромат**: Оперативные риски, уязвимости, привычки, поведенческий анализ и статус наружного наблюдения.

### 4. 🕸️ Интерактивный граф связей «Ловец Снов»
- Полноэкранный круговой холст-веб с концентрическими кольцами и динамическими нитями между объектом, банками, автомобилями, родственниками и базами утечек.

### 5. 📡 Сканер баз данных «Дымовые Сигналы»
- Поисковый каталог по 8 ключевым категориям утечек с охватом свыше **4.8 миллиардов записей**.

### 6. ⚡ Тотемный терминал (Cyber CLI)
- Интерактивная командная строка с командами `help`, `scan <fio>`, `dossier`, `totem`, `breaches`, `decrypt <hash>`, `eagle`, `export`, `clear`.

### 7. 📄 Экспорт в официальное PDF-досье
- Генерация PDF документа высокого разрешения с водяными знаками, тотемным гербом, грифом секретности и полной таблицей данных.

## 🚀 Запуск и открытие через GitHub

### 🌐 Вариант 1: Открытие через GitHub Pages (Мгновенно в браузере)
1. Включите **GitHub Pages** в настройках вашего репозитория:
   - Перейдите в `Settings` &rarr; `Pages`.
   - В разделе **Build and deployment** выберите источник **GitHub Actions**.
2. В репозиторий уже включен готовый рабочий процесс `.github/workflows/deploy.yml`.
3. Приложение автоматически соберется и станет доступно по ссылке:
   ```
   https://<ваш-username>.github.io/redskinassasin/
   ```

### 💻 Вариант 2: Локальный запуск на компьютере
```bash
# Клонируйте репозиторий
git clone https://github.com/karalik19-a11y/redskinassasin.git
cd redskinassasin

# Установите зависимости
npm install

# Запустите локальный сервер разработки
npm run dev
```

Сервер откроется по адресу: `http://localhost:5173`.

### 📦 Вариант 3: Сборка статического сайта
```bash
npm run build
```
Готовые оптимизированные файлы будут находиться в папке `dist/` (открываются через любой статический веб-сервер или Nginx).
